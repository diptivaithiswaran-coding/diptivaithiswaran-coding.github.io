# Dipti Vaithiswaran Portfolio

A static Jekyll site for publishing a personal portfolio through GitHub Pages.

## Site structure

- `index.md`, `about.md`, `work-experience.md`, `contact.md` — page content
- `_config.yml` — site metadata, base URL, and navigation
- `_layouts/` and `_includes/` — shared page structure and metadata
- `assets/` — CSS, the minimal theme-switching script, and the favicon
- `sitemap.xml` and `robots.txt` — search-engine discovery
- `README.md` — editing, local preview, GitHub Pages, and Lighthouse instructions

## Important constraints

- Keep the publishable Jekyll site at the repository root for the `main` branch and `/` (root) GitHub Pages source.
- Do not add a framework app, backend, database, contact form service, third-party trackers, or unnecessary dependencies.
- Use the pasted résumé only; do not fetch the LinkedIn URL.
- Keep the phone number off the public site. The email address is intentionally public.
- The creator-platform work is listed as Another. Its formal role and dates remain placeholders until provided.
